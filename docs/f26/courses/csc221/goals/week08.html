Project: Base64 Encoder

You and your partner have just been hired write a Base64 encoder / decoder. Your customer has told you that they want to be able to give your encoder any binary file as input and get back a text file containing only Base64 characters as output.

When they feed this same output text file into your decoder, they want to get back an exact copy of their original binary file.
