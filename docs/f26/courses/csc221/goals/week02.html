Overview

This week we will begin Chapter 2: Values, expressions and statements in our online textbook. We will then summarize the important ideas from Chapter 1: Why program? in our text.

By the end of this discussion you should understand:

  • the four things computers do
  • how information is represented in a computer
  • what a computer program is
  • why Python is a high-level, interpreted programming language
  • the difference between shell mode and script mode in running Python code
