## What we'll do in class

### Arlington Data API

Last class, we started to look at the [Arlington Open Data Portal](https://data.arlingtonva.us/),
which includes a fun set of easy-to-use JSON data APIs.

Today, we'll work together to build a Jupyter Notebook that accesses data about
dogs that live in Arlington. We'll spend some time looking at the data,
writing Python code to retrieve the data via the API, and making some charts
via [pyplot](https://matplotlib.org/stable/plot_types/index.html)

### Project

After we do this together, you'll work on your own project where you'll find a 
dataset from the Arlington website, write a few queries, and make a few visualizations.

Keep this project simple - we're not using Pandas (or Seaborn, or any other fancy
Python libraries) yet.

I'll have a full write-up about this project for you next time!
