# Session 0

## What We'll Do In Class

Hi! I'm Chris - it's great to see all of you. I already know almost everyone
in the class, but for the few new faces - it's nice to meet you =).

Unlike most CTE classes, this class is entirely Arlington Tech students - so 
we might be able to get started today.

There is an orientation for 10th graders in the gym. We have a few 10th
graders, so we'll let them go to the orientation. I don't really want them to
miss out on our course orientation, so we'll wait on them to return.

If we're all together before the end of the period, we'll start with course
orientation (motivated by [this flow chart](https://apscs.org/index.html?school=acc)
and the syllabus linked from [our course homepage](https://ict.gctaa.net/f26/courses/ite140/)).

In the meantime, the rest of us can get started on some setup tasks:

1. Make sure you can open Microsoft Excel on your computer. You might need
to login to MyAccess to activate it.
2. Make sure you have a git repo that you can use for this class. I'll let you
choose whether it's hosted on GitHub, Codeberg, or anywhere else. 
    - If you aren't sure how to do this, Your classmates and I
    will help you! [You can get started by following this guide](../../../resources/git_on_github/index.html)
3. Write and publish a simple HTML homepage that you'll use for this course.
4. Add an `intro.html`, which answers these questions:
    - Who are you? What do you want us to know about you? Do you have any
    fun facts, stories, hobbies, that would help us get to know you as a 
    member of our class community?
    - Why are you here? What motivated you to sign up for this class? What 
    do you hope to learn?
    - What academic background do you bring? Specifically, I'd like to know how 
    much experience you have with:
        - Spreadsheets
        - Databases
        - Statistics
        - Python
        - HTML
    - What can we do to help you succeed? This can include "classroom charter" 
    type suggestions, things that you look for in group projects, etc.

I'll make one of these, too. Next class, we'll all present our introductions.
