### Git orientation

Sorry if I overwhelmed some of you in the first week! This class has a broad range of backgrounds, and I want to make sure everyone has what you need to participate.

We'll spend as much time as we need today getting our github accounts setup. My understanding is that everyone in this class has either:

- Taken my web design class
- Taken [ITE152](https://www.nvcc.edu/courses/ite/ite152.html) at NOVA, which includes "Develop a simple webpage using a text editor or html editor that contains basic tags, such as title, headers, links, multimedia and images"

So I think it's fair to ask everyone to submit assignments via an HTML page. We'll spend some time making sure we're all there.

Even students who have been with me before might benefit from this discussion because I'm going to show you how to use 
[Github Codespaces](https://github.com/features/codespaces) for this part. It's 
worth following along because we'll have some assignments later in the
year that will require using Codespaces.
