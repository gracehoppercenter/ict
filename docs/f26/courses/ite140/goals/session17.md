## What we'll do in class

### Arlington Data API Project

Happy Friday - today, you'll start working on your own dataset from the 
Arlington Data API: <https://opendata.arlingtonva.us/>. Thanks to James
for pointing out that some datasets on that website are more complicated than others.
You're encouraged to click around and find one that's really easy.

I'll have the full write-up for this project next time. For today, get started 
by picking a dataset and practicing making queries against it. You can
refer to the documentation here: <https://docs.data.arlingtonva.us/resources/#api>

If you want to look at my sample implementation, [I've committed it here](https://codeberg.org/cjones/ITE140/src/branch/main/arlington_dog_api.ipynb). Note that Codeberg represents 
as raw JSON - if you download that file and open it in VSCode, it'll look 
like the jupyter notebook you're used to.
