# Favicon and Github Profile

## Assignment Purpose

Give your website and your Github account a professional, personal touch. These
two activities count together as a single classwork assignment.

## Part 1: Favicon

Your website needs a favicon!

Draw your own icon using this website: <https://www.favicon.cc/>. It's totally
possible that website is blocked - if that's the case, you can google to find a
new one. If you find a good one, share with your classmates!

Remember, the website that we're building this year should be professional,
school-appropriate, and unique to you. Your favicon should be the same!

Then add it to your website using the sample code from the edube reading
("Favicons" in Module 6 - if you haven't done that reading, start there).

## Part 2: Github Profile

Your Github account is a fantastic portfolio that you can use to connect with
other programmers and demonstrate your experience to employers. So far this year,
we've focused on using Pages to create a custom HTML page. Now, add some
customization to your profile on Github. As an example, take a look at this
profile of a student who recently graduated: <https://github.com/BlueZeeKing>

(I actually keep my personal profile on Codeberg, another website that works
almost exactly the same as Github: <https://codeberg.org/cjones>)

- Add a profile readme, following the instructions here:
  [Profile Readme](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme)
- Update your avatar to something other than the default
- Add a bio, [following these instructions](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/using-your-github-profile-to-enhance-your-resume#step-1-create-a-professional-bio)

As always, the information that you're writing here is available on the public
internet. I expect that everything you post here is professional, and I have no
requirement that you share any personal information. Please let me know if you
have any concerns with this assignment, or with our use of Github!

## Submission

Commit and push your favicon and the updated `index.html` that links it. Check
that DUCK can see your homepage: <https://duck.apscs.org/file_list?path=index.html>

Your Github profile changes are visible on github.com - nothing to submit there.

## Grading

One classwork grade for both parts.
