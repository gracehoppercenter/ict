# Terminal / Vim Lesson Page

## Assignment Purpose

Practice the semantic HTML we've learned so far by writing a page that teaches
something you know well: the terminal or vim.

## Requirements

Make a new HTML page in your repo called `practice/terminal.html`. In this page,
write a nice html page that I might use to teach one of my lessons next year on
either the Terminal or Vim. You can start by looking at the session calendar, but
I'll expect that you include more code snippets and examples that you gained from
vimtutor and/or terminus.

For example, you might make an HTML page about vim - I would expect that page to
include instructions about how to open/close vim, how to save files, and some of
the most useful vim commands.

I'll expect that your page has:

- All of the elements from the minimal *semantic* HTML page (`<header>`, `<main>`,
  `<section>`, `<footer>`), and the validator script.
- An ordered list and an unordered list, used appropriately
    - e.g. use an ordered list to give specific instruction steps, and an unordered
      list to provide a list of features
- A few `<pre>` / `<code>` elements, used appropriately
    - pay attention to the way that they used `&lt;` in the `<pre>` element in the
      edube page titled "Paragraphs and Text Formatting – Part 4"
- A few `<kbd>` / `<samp>` tags, used appropriately

Remember that we haven't really learned CSS yet. I expect that this page will just
be black text on a white background - we're focusing on semantic correctness first!

## Submission

Classwork grade. The page must be valid for full credit.
