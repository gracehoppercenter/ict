# Git Repo Setup

## Assignment Purpose

We'll use git and Github to publish everything we write in this class. This
assignment gets your repo set up and connected to DUCK, our auto-grader, so that
I can see (and grade) all of your work for the rest of the year.

## Requirements

1. Follow [the Git on Github tutorial](../../../resources/git_on_github/index.html)
   to set up git on your computer and create your Github Pages repo.
2. Make sure you can change a file on your computer and have that change show up
   on your Github account (add / commit / push).
3. Make an account on DUCK, our auto-grader: <https://duck.apscs.org>. Share your
   Github account and your repo's name.

The auto-grader is strict about organization, so I'll be strict about making sure
our repos all have the same structure. Your homepage must be `index.html` at the
top level of your repo.

**Publishing is optional.** This class is about building websites, but you can
get a 100% for both APS and NOVA without ever publishing a public website. If you
don't want your work to be public, let me know and you'll publish to a private
location that only you and I share.

## Submission

Check that your repo shows up on DUCK:
<https://duck.apscs.org/file_list?path=index.html>. Select your section, click
"Submit Query", then click the link next to your name.

## Grading

This is graded 5/5 or 0/5. If your repo doesn't show up on DUCK, I have no way to
grade any of your assignments for the rest of the year, so please get it fixed
ASAP! Let me know if you think you did everything right - it's very possible that
the 🦆 is confused =)
