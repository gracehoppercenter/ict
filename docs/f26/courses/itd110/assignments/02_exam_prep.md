# WDE Exam Prep: Self-Assessment

## Assignment Purpose

We're halfway through the semester, which means we're also halfway through
preparing for our HTML certification exam (the JS Institute WDE exam). This
assignment will help you take stock of what you know so far, and what you
still need to study.

## Requirements

First, look over the
[WDE Exam Objectives on our competencies page](../competencies/#fw-WDE).
For each objective, that table shows which sessions and assignments we've
already covered it in. Use those links to jog your memory, or to review a
topic you're not sure about.

Next, create a new file in your repo at `practice/exam_prep.md`, and
copy/paste the template below into it.

Next to each objective, give yourself a "confidence score" that represents how
confident you feel that you will get a question about that topic right. Use a
letter grade scale (A means you are very confident you will get a question
about that topic correct, E means that you are very confident you will get a
question about that topic wrong).

Some of these topics we haven't covered yet in class - that's okay! Score
those honestly too.

This is a completion activity and I won't use your confidence scores to
calculate any grade - so feel free to be honest! We'll use this to inform our
study plan for the test.

When you're done, pay attention to any topics that you gave a low score to,
and start reviewing those topics on your own in Edube.

### Markdown

Note that this file ends in `.md`, not `.html`. This is NOT an HTML file. 
Markdown is another language that's meant to be very easy to read and write. Markdown is very popular online - it's the language that Wikipedia is written in, and it's actually the language that I use to write almost everything on our course page.

You'll find that Markdown is very easy to learn. For a nice starter guide, see [Markdown Guide](https://www.markdownguide.org/). 

One nice thing about Markdown is that github automatically/magically converts it to 
nice-looking HTML. So you'll notice that the file you're creating today is `practice/exam_prep.md`, but after you push to your repo it'll be hosted on your website as `practice/exam_prep.html`. That's the file name that you'll see in DUCK.
