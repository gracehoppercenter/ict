# Grid Practice: Box of Chocolates

## Assignment Purpose

Practice CSS grid by placing shapes in an orderly grid layout.

## Requirements

I've written you some starter code:
<https://github.com/cj0ne5/cj0ne5.github.io/blob/main/practice/chocolates.html>.
Copy this to your own `practice/chocolates.html`.

Fill in the rest of the chocolate box, using divs that you shape with code from
<https://css-shape.com/>. There are a lot of boxes to fill, so feel free to add a
big chocolate bar that spans a few boxes, and to repeat shapes.

## Submission

Commit and push `practice/chocolates.html`. Check that DUCK can see it:
<https://duck.apscs.org/file_list?path=practice/chocolates.html>

## Grading

Classwork grade.
