### Vim Tip Of The Week - Yank/Paste
This will be the most intricate document we've written in vim so far, and you'll likely want to do some copy/pasting. 

We'll introduce a few new commands for this purpose:

- `y` copies text you've selected in visual mode 
- `d` which cuts text you've selected in visual mode 

And their normal mode variants that work on entire lines: `yy`, and `dd`.

[Here's a nice guide that should help you out](https://www.warp.dev/terminus/vim-copy-paste), and I always recommend periodically reviewing vimtutor to pick up new tips and tricks.
