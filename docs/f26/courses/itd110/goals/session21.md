By the end of this lesson, you should:

## What We'll Do In Class

### CSS Grid

Flex is one of two very powerful tools that we'll need when we start looking
at page layouts. The second, which I'll introduce today, is CSS Grid.

We'll look at some examples of grid in the wild,
 and we'll play with [https://cssgridgarden.com/](https://cssgridgarden.com/) 
(which is made by the same person as Flexbox Froggy).

### Grid Practice: Box of Chocolates

Just like our last activity, we'll place shapes on a page - but this time we'll
use grid to keep our shapes a little more orderly.
