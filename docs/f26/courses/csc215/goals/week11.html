Classwork

I read Chris's comments about where you are on completing the calculator program. I also looked at Mason's source code. I'll confirm with Chris when I see him Monday morning, but it seems clear to me that one more day to bring this to final form is more than warranted.

The full smash would be a program that:

  1. Loads and sends a welcome message to the TTY followed by a blank line, and then a prompt that looks like this: => .
  2. The user would then be able to enter a postfix expression, like this: 
    => 3 4 + 5 *
  3. When the user sent the Enter key, they would then see: 
    35
=>
  4. Lather, rinse, repeat ;-) If we think we can reach this Holly Grail in the near future, I vote we continue our quest.

Homework / Evaluation

Instead of a quiz, I think we should make a working version of the program as described above our success metric, and give everyone who worked on the project an A upon delivery. Let's discuss this at the beginning of class.
