CSC 215

Week of Monday, November 16, 2026

Overview

This week we will move to the computing environment we will be using for the rest of the course (and beyond), the Altair Z80 with CP/M.

Monday, November 16th

Classwork

Our textbook has been updated with an Appendix C: Altair Z80 Setup describing how to setup our new computing environment. We will start today by going through that.

After setting up our new environment, we need to begin learning how to use it. We'll want two new skills before we can begin writing C programs:

  1. Basic usage of the CP/M Console Command Processor
  2. Ability to use the WordMaster text editor included with our new computing environment to edit text files

Appendix D: CP/M Cheat Sheet and Appendix E: WordMaster Cheat Sheet should be all we need to accomplish these two learning goals.

Homework

Using the resources provided, familiarize yourself with both the basic CP/M commands and the WordMaster editor.
