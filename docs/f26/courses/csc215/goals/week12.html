To get things moving, here are a few simple assembly programs we can assemble and run. We'll begin with the classic Hello World! program. 

; HELLO.ASM - Print a string to the console
BDOS    EQU     0005H       ; BDOS entry point
PRTSTR  EQU     09H         ; BDOS function 9: Print String

        ORG     0100H       ; CP/M programs always start at 100H

START:  LXI     D, MSG      ; Load address of message into DE
        MVI     C, PRTSTR   ; Load function 9 into C
        CALL    BDOS        ; Call CP/M to print the string
        RET                 ; Return to CP/M prompt (CCP)

MSG:    DB      'HELLO FROM THE ALTAIR 8800!$'

        END     START

Here's one that echos keys and traps ^C to quit. 

; ECHO.ASM - Echo keystrokes until Ctrl+C is pressed
BDOS    EQU     0005H       ; BDOS entry point
CONIN   EQU     01H         ; BDOS function 1: Console Input
CONOUT  EQU     02H         ; BDOS function 2: Console Output
CTRLC   EQU     03H         ; ASCII code for Ctrl+C

        ORG     0100H

LOOP:   MVI     C, CONIN    ; Read character into A (also echoes automatically)
        CALL    BDOS
        CPI     CTRLC       ; Compare A with Ctrl+C
        JZ      EXIT        ; If Ctrl+C, exit to CP/M

        ; Print brackets around the character to show our program processed it
        PUSH    PSW         ; Save the character in A on the stack
        MVI     E, '['      ; Load '[' into E
        MVI     C, CONOUT   ; Print '['
        CALL    BDOS

        POP     PSW         ; Restore the typed character into A
        MOV     E, A        ; Move it to E for printing
        MVI     C, CONOUT   ; Print the character
        CALL    BDOS

        MVI     E, ']'      ; Load ']' into E
        MVI     C, CONOUT   ; Print ']'
        CALL    BDOS

        JMP     LOOP        ; Repeat forever

EXIT:   JMP     0000H       ; Warm boot CP/M (safe exit)

        END     LOOP

And this one prints the ASCII characters from 'A' to 'Z'. 

; ALPHA.ASM - Print A through Z
BDOS    EQU     0005H
CONOUT  EQU     02H

        ORG     0100H

START:  MVI     B, 'A'      ; Starting character
        MVI     D, 26       ; Loop counter (26 letters)

NEXT:   MOV     E, B        ; Move current letter to E for BDOS
        MVI     C, CONOUT   ; Function 2: Console Output

        PUSH    B           ; Save B and C (BDOS destroys registers!)
        PUSH    D           ; Save D and E
        CALL    BDOS        ; Print character
        POP     D           ; Restore D and E
        POP     B           ; Restore B and C

        INR     B           ; Increment ASCII character ('A' -> 'B')
        DCR     D           ; Decrement loop counter
        JNZ     NEXT        ; Jump back to NEXT if D is not zero

        RET                 ; Return to CP/M

        END     START

That should be enough to get you going. Have fun!
