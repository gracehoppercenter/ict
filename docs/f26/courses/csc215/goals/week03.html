CSC 215 Weekly Assignments: Week 3

CSC 215

Week of Monday, September 14, 2026

Overview

This week we will be introduced to the MITS Altair Simulator Program Converter and learn to use it to write machine code programs for the Altair 8800.

Monday, September 14th

Classwork

Today in class Chris and Nathan will present their program to find the index of the largest positive integer in a sequence of ten positive integers.

They will be introducing how both looping and branching are written in machine language using jump instructions.

Pay close attention and ask questions! You will need to understand this and be able to use it to write your own programs soon.

Homework / Evaluation

Read the instructions for how to use the MITS Altair Simulator Program Converter. Then download add2_16bit_numbers.spc, convert it to binary, load it into the simulator, and run it.
