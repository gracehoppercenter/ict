Project: Four Function Postfix Calculator

Write an assembly language program using the ASR-33 for I/O that implements a four function (+, -, * and /) Reverse Polish notation calculator on 16 bit signed integers. A sample run of your finished program might look like this: 

=> 256 4 +
260
=> 2 3 4 * +
10
=> 2 3 4 + *
20
