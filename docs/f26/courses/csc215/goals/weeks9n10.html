During class, we setup a shared repo at https://codeberg.org/GHC_Students/stackpancake. We added branch protection to main, and agreed that we'll use PRs to submit code.

We also discussed how all of the functions we're working on will interface with each other. Here's what we decided so far:

  • Each function will expect that when it's called, its operands are already loaded into the register pairs BC/DE
  • After each function ends, it'll put its result in the HL register pair
  • Each function will preserve everything in memory, with the exception of Mult, which needs to be able to store a counter at address 0x00FF
  • This means that main will be responsible for:
    • input/output
    • parsing the math expression into a stack and maintaining the stack
    • making sure that BC/DE are all set before calling a function, and grabbing results from HL
    • making sure that none of this interferes with the instructions in memory that start at 0x0000, or with the single-byte counter at 0x00FF

Reverse Polish Notation

Reverse Polish notation also called postfix notation is a mathematical notation that places operators after their operands. It was used by several HP calculators in the late 1960s and 1970s, starting with the HP 9100A.

Since postfix notation removes the ambiguity associated with infix notation, it eliminates the need to use parathensis for grouping. Here are some examples to illustrate this: 

Infix: (3 + 5) * (7 - 2)
Postfix: 3 5 + 7 2 - *

Infix: 1 + 2 * 3
Postfix: 1 2 3 * + 

Infix: (1 + 2) * 3
Postfix: 1 2 + 3 * 

Infix: (3 - 1) * (2 + 4) / 5
Postfix: 3 1 - 2 4 + * 5 /
