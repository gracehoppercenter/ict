Reverse Polish Notation

Reverse Polish notation also called postfix notation is a mathematical notation that places operators after their operands. It was used by several HP calculators in the late 1960s and 1970s, starting with the HP 9100A.

Since postfix notation removes the ambiguity associated with infix notation, it eliminates the need to use parathensis for grouping. Here are some examples to illustrate this: 

Infix: (3 + 5) * (7 - 2)
Postfix: 3 5 + 7 2 - *

Infix: 1 + 2 * 3
Postfix: 1 2 3 * + 

Infix: (1 + 2) * 3
Postfix: 1 2 + 3 * 

Infix: (3 - 1) * (2 + 4) / 5
Postfix: 3 1 - 2 4 + * 5 /

A List of Subroutines

To help make this problem more tractable, we should create a collection of subroutines, a list of which might include:

  • ADD
  • SUB
  • MULT
  • DIV
  • INT (To convert a sequence of digits into an integer)
  • ISDIG
  • ISOP
  • PARSE (To process the input string)
  • EVAL (To coordinate calling the appropriate subroutines)

We'll talk a bit about this in class today before letting you get back to work on the project.
