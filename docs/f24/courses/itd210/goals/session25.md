## Lesson Objectives

By the end of this lesson, you should:

- **Understand** how to use keyboard events (`keydown` / `keyup`) in JavaScript
- **Be able to** track user input using a key state object
- **Be able to** move an object on the canvas using user input (arrow keys)
- **Understand** the difference between automatic motion and input-driven motion
- **Be able to** add and update multiple shapes on the canvas at once

### Activity: Add a Player

We'll add a new "player" rectangle that we can control with the arrow keys.
To do this, we'll need to learn a few new Javascript concepts:
- Objects
- Anonymous Functions
- Event Listeners

### You Do
We moved the player using the up arrow key. On your own, you'll add the rest of 
the arrow keys.

As an extension, decide what should happen when the player hits the wall. Should
they loop back to the other side of the screen? reset to a random position?
