### Activity: What should happen when the player hits the edge of the screen?

As an extension, decide what should happen when the player hits the wall. Should the wall just be impenetrable? Should
they loop back to the other side of the screen? reset to a random position?

Decide what should happen, and add update the code in your `movePlayer()`.


### Activity: Add score and game state

We'll create a simple score and add it to your game. We'll also introduce game
state. As a simple introduction, we'll have the gaem automatically end after 
1000 frames.

### Activity: Collisions

Our game will be way more interesting once we add some collision logic. We'll
review a technique called `Axis Aligned Bounding Boxes`. This code is easy, but
the logic is tricky. So we'll take it slow!

### Activity: Randomness

We'll play with `Math.random()` to make our game a little more interesting.
