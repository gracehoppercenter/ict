GHC Locally Building Our Textbooks

Process Description
Clone the Repo

The repos for all our textbooks are on Codeberg:

  • Web Publishing for a Better World
  • Beginning Python Programming for Aspiring Web Developers
  • A C++ Book for Undergraduate Computer Science Majors
  • Demystifying Computers

We should be able now to just tell you to clone the repo in a good location and you should know what to do. (Note: If you don't, we have failed in our misssion ;-)

Build the Book
  1. % python3 -m venv venv
  2. % source venv/bin/activate
  3. (venv) % pip install sphinx
  4. (venv) % make html
Rename, Read and Enjoy!

The new build directory created in the previous step contains the textbook. Load the index.html in a web browser and enjoy!
