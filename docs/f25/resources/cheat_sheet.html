Terminal, Vim & Git Cheat Sheet

This page is a work in progress. Please suggest changes!

Terminal

(Config file: ~/.bashrc or ~/.zshrc)

  • cd <path>
    Change directory to specified path
  • cd ..
    Move up one directory level
  • cd -
    Move to the last-visited directory
  • cd ~
    Go to home directory
  • ls
    List directory contents
  • ls -al
    List all files (including hidden) with details
  • pwd
    Print working directory (show current path)

Running Commands In The Terminal

  • Tab
    Auto-complete
  • Ctrl+C
    Stop running command

File Operations

  • mv <source> <dest>
    Move or rename files/directories
  • cp <source> <dest>
    Copy files/directories
  • rm <file>
    Remove a file
  • rm -rf <folder>
    Force remove directory and all contents
  • mkdir <name>
    Create a new directory
  • cat <file>
    Display file contents
  • less <file>
    Display file contents - includes paging for long files.

Vim

(Config file: ~/.vimrc)

File Operations

  • vim <file>
    Open file in vim (from terminal)
  • :wq
    Save and quit
  • :w
    Save file without quitting
  • :q!
    Quit without saving
  • :e <file>
    Edit a new file

Navigation (Normal Mode)

  • h j k l
    Left, Down, Up, Right (arrow keys also work)
  • 0 (zero)
    Move to beginning of line
  • $
    Move to end of line
  • w
    Move to start of next word
  • e
    Move to end of current word
  • *
    Move to next repeat of current word under cursor
  • %
    Move to matching bracket
  • gg
    Go to first line of file
  • G
    Go to last line of file
  • Ctrl+f / Ctrl+b
    Page forward / backward

Modes

i Insert mode
a Insert mode after cursor
A Move cursor to end of current line, and then switch to insert mode
o Add a new blank line below current, move the cursor there, and switch to insert mode
v Visual mode (character)
V Visual-line mode
Esc Normal mode

Editing & Yanking

  • yy
    Yank (copy) current line
  • :reg
    Show all registers
  • p
    Paste after cursor
  • "0p
    Paste from yank register
  • "+p
    Paste from system clipboard
  • dd
    Delete (cut) current line

Window Splits

  • :vsp
    Vertical split
  • :sp
    Horizontal split
  • Ctrl+w <h,j,k,l>
    Move between splits
  • Ctrl+w < or >
    Resize split width
  • Ctrl+w =
    Equalize split sizes

Buffers

  • :ls
    List all buffers
  • :b<number>
    Switch to buffer number

Git

(Config file: ~/.gitconfig)

Basic Workflow

  • git status
    Check status of working directory
  • git add <file>
    Stage file for commit
  • git add .
    Stage all changes
  • git commit -m "message"
    Commit staged changes with message
  • git push
    Push commits to remote repository
  • git pull
    Fetch and merge from remote

Branches

  • git branch
    List all branches (current highlighted)
  • git branch <name>
    Create a new branch
  • git checkout <branch>
    Switch to branch
  • git checkout -b <branch>
    Create and switch to new branch
  • git merge <branch>
    Merge specified branch into current
  • git push -u origin <branch>
    Push branch to remote and set upstream

Additional Useful Commands

  • git clone <url>
    Clone a repository
  • git log --oneline
    Compact commit history
  • git diff
    Show unstaged changes
  • git stash
    Temporarily save changes
  • git stash pop
    Re-apply stashed changes
  • git reset <file>
    Unstage file
