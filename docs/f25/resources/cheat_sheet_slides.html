TERMINAL

Terminal Navigation

  • cd <path>
    Change directory to specified path
  • cd ..
    Move up one directory level
  • cd -
    Move to the last-visited directory
  • cd ~
    Go to home directory
  • ls
    List directory contents
  • ls -al
    List all files (including hidden) with details
  • pwd
    Print working directory (show current path)
Pro Tip:
Use Tab for auto-completion

TERMINAL

File Operations

  • mv <source> <dest>
    Move or rename files/directories
  • cp <source> <dest>
    Copy files/directories
  • rm <file>
    Remove a file
  • rm -rf <folder>
    Remove directory and all contents
  • mkdir <name>
    Create a new directory
  • cat <file>
    Display file contents
  • less <file>
    Display file contents, with paging for long files

VIM

Vim Basics

File Operations

  • vim <file>
    Open file in vim (from terminal)
  • :wq
    Save and quit
  • :w
    Save file without quitting
  • :q!
    Quit without saving
  • :e <file>
    Edit a new file

VIM

Vim Navigation

Movement Keys

  • h j k l
    Left, Down, Up, Right
  • 0 (zero)
    Move to beginning of line
  • $
    Move to end of line
  • w
    Move to start of next word
  • e
    Move to end of current word
  • gg
    Go to first line of file
  • G
    Go to last line of file

More Vim Navigation

Movement Keys

  • *
    Move to next repeat of word under cursor
  • %
    Move to matching bracket
  • /<pattern>
    Search forward for pattern
  • n
    Move to next search result
  • N
    Move to previous search result

GIT

Git Basic Workflow

  • git status
    Check status of working directory
  • git add <file>
    Stage file for commit
  • git add .
    Stage all changes
  • git commit -m "message"
    Commit staged changes with message
  • git push
    Push commits to remote repository
  • git pull
    Fetch and merge from remote
  • git clone <url>
    Clone a repository

GIT

Git Branch Management

  • git branch
    List all branches (current highlighted)
  • git checkout <branch>
    Switch to branch
  • git checkout -b <branch>
    Create and switch to new branch
  • git merge <branch>
    Merge specified branch into current
  • git push -u origin <branch>
    Push branch to remote and set upstream

GIT

Git Useful Commands

  • git log --oneline
    Compact commit history
  • git diff
    Show unstaged changes
  • git stash
    Temporarily save changes
  • git stash pop
    Re-apply stashed changes
  • git reset <file>
    Unstage file
  • git fetch
    Download objects without merging
