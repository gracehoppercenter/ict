### Test Prep

- Format: This test will look and feel just like the last one. Here's a summary
    - 20 multiple choice questions and 2 free response questions. 
    - You are allowed to make and use a "cheat sheet" - it must be hand written and a single page (feel free to write on the front and back).
    - No calculators, and no flippy-do (if you think you'll need them, you might 
    want to make some notes about powers of 2 and/or multiples of 16 on your
    cheat sheet)
    - Remember - no retakes!

Here are a list of topics that are fair game for the test. 

- The four layers of the TCP/IP Model, and what they each do
    - Application Layer:
        - HTTP request/response cycle, GET vs POST requests
        - The World Wide Web is just an application that runs over the internet
    - Transport Layer:
        - TCP vs UDP
    - Internet Layer:
        - IP addresses
        - Routing Tables
    - Link Layer:
        - Recognize some protocols: ethernet, wifi, bluetooth
    - Header vs Payload
    - Error Correction
- Data representation in Binary:
    - Numbers in Binary, Hex, and Decimal
        - Conversions between them (I won't give you any values bigger than 8 bits /
        2 hex digits)
        - Addition and subtraction in binary
    - ASCII
    - RGB Colors
- Internet Security:
    - Adversary-in-the-middle attacks
    - HTTP vs HTTPS (and the lock symbol in the browser)
    - Symmetric vs Asymmetric Encryption
    - The role of public/private keys in asymmetric encryption

I will not ask about these topics:
- Any details about any of the protocols we didn't go over in class
- Any specific details about the Signal protocol (we're using it as a real-world
example for how we use symmetric/asymmetric encryption, I don't need you to know
more than that)
- Bitwise operators (And, or, bitshifts, xor, not)
