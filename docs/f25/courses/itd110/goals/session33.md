### Test Prep

- Format: This test will look and feel just like the last one. For a summary
of the test format, go back to session 24. There is no project for this unit, so I'll have a short activity for you to work on after the test.

This unit was pretty broad. There were a lot of readings. We hit the highlights in class, but everything in the readings is fair game. Here are a list of topics you should review for the test. 

- Three ways to add CSS to an HTML document:
    - Inline styles (using the `style` attribute on any HTML element)
    - Internal styles (using the `<style>` element
    in the `<head>` of your HTML document)
    - External styles (using a separate file and the `<link>` element)
- CSS selectors for elements, classes, and ids
- divs and spans
- Favicons (and the `favicon.ico` file)
- CSS rules:
    - background-color
    - border
    - font-family
        - serif vs sans-serif vs monospace
    - The box model:
        - Content
        - Padding
        - Border
        - Margin
- HTML Forms:
    - GET vs POST
    - Actions
    - Input Types
    - Labels and Fieldsets
- `<video>` and `<audio>`
    - Lossy vs Lossless compression
- Specifying CSS colors with names, RGB, hex
- HTML Entities
- Accessibility: WCAG, contrast, ARIA
- iFrames
- Image Maps

I will not ask about these topics:
- Recognizing any specific fonts
- Any specific media codecs
- You just need to know the concept of ARIA states, roles, and properties. I won't ask about any specifics
- You just need to know the concept of WCAG. I won't ask about any specific requirements.
