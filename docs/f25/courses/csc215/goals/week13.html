CSC 215 Weekly Assignments: Week 13

CSC 215

Week of Monday November 17, 2025

Overview

We meet three times this week and the start of next, so we will combine these together into week 13. With hard work and a bit of good fortune, we can finish our goal of using reading data from a disk, processing it, and writing it back out, bringing closure to our study of assembly language.

We can then return from Thanksgiving break to start week 14, and move from assembly language to the higher leven and much more human friendly language C.

Project: File I/O

We'll start class the beginning of the week with our summary presentation of Chapter 15: The File Control Block.

After that we'll work on our final projects for our study of assembly language. You'll keep the same pairs you had for the previous project, and use the same algorithm you used in the last project as well.

This time, however, you will:

  1. read your input data from a disk.
  2. do some meaningful processing of that data (the same processing as you did with the CLI version of your program).
  3. write your output data to a disk.

Be ready to present them on our first day back from Thanksgiving break.
