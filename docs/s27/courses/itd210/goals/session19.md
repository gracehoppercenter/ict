### Setup for our game project

Our goal for the upcoming project will be to share a single repo with your teammates.

This is going to be challenging given the ongoing network issues with Github, so
we're going to switch to <https://codeberg.org/> for this project. Codeberg works
just like Github, so I think you'll find that you learn it very quickly =)

To start, register for an account on 
Codeberg: <https://codeberg.org/user/sign_up>. Once you have an account, you'll
need to set it up to work with the SSH keys in your terminal. You can reuse the 
same SSH keys that you setup at the beginning of the year for Github, so 
You can start with step 9 on these instructions: <https://ict.gctaa.net/f25/resources/git_on_github/reimage.html>

From there, you and the folks at your table will create a practice shared repo.
We'll have a conversation in class about how to share a repo. The emphasis
will be on remembering to "always pull before you push".

We'll also talk about "merge conflicts" which are what happens when the "pull
before you push" process goes wrong. These conflicts can look scary, but they're
easy to deal with. We'll practice intentionally creating these conflicts and 
resolving them.
