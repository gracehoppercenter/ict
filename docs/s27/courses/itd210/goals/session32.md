## JSE Certification Prep

Our JSE Certification (AKA your final exam!) is next class!
As a reminder: 
[I've downloaded the exam syllabus and placed it here](../info/jse_exam_syllabus_S26.pdf). 
That document lists the topics on the exam, and those topics should match 
one-to-one with questions on the exam. 

Today, we'll take the official practice test at the end of the
JSE Edube Course. If you're already logged in, you can click this link to jump 
to the test: <https://edube.org/quiz/jse1-1-0-1/jse1-final-test-1>. 

The real test has 30 questions and is timed for 40 minutes. This practice also 
has 30 questions, but I won't enforce any time limit.
You will certainly encounter new things we haven't learned together in class, 
but I'm confident that you'll be able to make enough good educated guesses to 
get to a 70% score!

Feel free to use this test however is most useful for you. You might choose to 
practice like it's a real exam, or you're welcome to use any resources you need 
to learn as you go. I personally kept a node window open so that I could test 
out code I was unsure about - and you're welcome to ask me for explanation, too.
