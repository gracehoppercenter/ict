You know the drill:

- 45 minutes
- 20 multiple choice questions

Here's a list of topics you should be comfortable with:

- What is JavaScript, and where does it run?

- Valid variable names
- let vs const
- prompt()
- Shapes in js canvas

- Use if statements (else, else if)
- Boolean expressions (&& || !)
