## What We'll Do In Class

### Introduce HTML Canvas
We'll spend a lot of time this semester playing with an HTML element called
`<canvas>`. Canvas is made for Javascript - there are a bunch of Javascript
functions that can draw shapes onto a canvas. It's a fun, easy, visual way to 
explore Javascript while we're learning it.

Today, we'll go through some simple examples together. They all come from this
website: <https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial>

To practice with sizes and positions, we'll do a few examples together:
- a small red circle in the top-left of the canvas
- a big blue circle in the exact middle of the canvas
- a big green rectangle that takes up the entire canvas

I won't grade these - so feel free to make up your own examples.
