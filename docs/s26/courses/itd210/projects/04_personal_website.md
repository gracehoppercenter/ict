### Static Site Generators

Many of you have noticed this year that writing HTML is a lot of work. HTML code
is long and repetitive, and if you want multiple pages in your website to
have the same structure you end up needing to repeat a lot of the same HTML
on every page.

Static site generators ("SSG") are the solution to that problem! With an SSG, 
you can write simpler "templates" and then run a program on your computer that
turns those templates into complete HTML pages that you can publish like normal.

There are tons of popular SSGs out there, but the one that I'd like to suggest
is called **Eleventy** (also written "11ty", and it's in the process of rebranding
to "Build Awesome") <https://www.11ty.dev/>. The cool thing about 11ty is that
the code you run on your computer is JavaScript - so it'll be a great way to 
combine the skills you 
learned in ITD210 with the skills you learned from ITD110. There is tons of good
information about 11ty online, and I'll give you an overview of 
this repo in class: <https://github.com/11ty/eleventy-base-blog>

### Grading

When I write recommendation letters, I like to be able to link to student portfolios
as evidence of all the great work students have done. Instead of the complex
rubrics I usually use, I'm going to assign a grade based on how I'd feel writing
a recommendation letter that links to your portfolio:

- 100% If *I* am proud of *your* website because it looks so good that I believe it's a good
example of everything I taught in class this year. I'll use these projects in 
future years as an example what you can learn in this class. For this grade, I 
specifically care that your code is good - I'm looking for code that clearly applies
the concepts we learned in class this year, not hundreds of lines of slop 
that we didn't learn.

- 89% If your website is complete and functional but missing that wow factor. I 
would include a link in a recommendation letter only if it was necessary to 
explain a project.

- Lower grades if I would not be excited to link to your website because it
is incomplete, not functional, or unattractive.
