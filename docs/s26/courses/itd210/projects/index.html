Project Grading

Each project will be graded in two parts:

  • 50% of your grade will come from your code, based on the rubric provided on the project page.
  • 50% of your grade will come from an in-class written exercise where you will explain how your code works

The table above includes two dates: the deadline to submit the project, and the date of the in-class writing exercise. For the in-class writing exercise, I will print your code and ask you to annotate it.

The code printouts will be in black-and-white, in a monospace font. All code formatting (line breaks/indentation) will be preserved from your source file, but I will add line wraps for lines that are longer than 80 characters. I will also remove all comments from the printed code.

I will also provide sample code from a project that does complete all of the project requirements. If you do not submit code in time, or if your code is incomplete, you can use my code for the writing portion.
