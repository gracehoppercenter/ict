# Self Portrait Project

## Project Introduction

To practice drawing shapes in HTML Canvas, you'll make a self-portrait. 
Feel free to give your portrait any theme, but you should consider yourself 
and what background/setting/items are around you.

This will count as a mini project - it will be weighted half as much as our 
normal projects.

To get full credit, your art should be pretty detailed. (I won't count shapes,
but I have some guidance in the rubric below).

You should have a thoughtful mix of shapes, including:
- arcs
- rectangles
- custom polygons (using `lineTo()`)

You should also have some comments that help me understand 
what your code is doing. (eg above the section where you make all the shapes
for your let eye, add a comment that says "//left eye")

## Submission Instructions

Put this project in a directory in your repo called `projects/portrait/`

In there, you should have at least two files:

- `index.html`
- a js file that is linked to the index

This project is due at the beginning of the school day on Tuesday, February 17th.

## Grading

The goal of this project is to demonstrate mastery of Canvas shapes and positioning.

I won't grade your artistic ability - as long as it looks like you are trying,
the result looks like you, and it's clear that you 
understand how to create and place shapes, you'll be fine.

As always, I'll subtract points if you can't explain how your code works or if 
your git history doesn't show that you wrote the code incrementally.

Instead of a normal rubric, I'll keep this one simple:

- 100%: Clear mastery of canvas shapes and colors (at least 25 shapes, variety of types)
- 85%: Good understanding of shapes and colors, but could be more detailed (15-24 shapes, variety of types)
- 70%: Ok use of shapes and colors but not much detail (10-14 shapes, some types missing)
- Below 70%: Minimal effort or incomplete submission
