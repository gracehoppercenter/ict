## What We'll Do In Class

### Chat with some guests

Some guests will stop by to propose a few Django project ideas.

### Team Project Work

We'll keep on keepin' on.

Each team should have a bunch of PRs to merge. We'll start with code reviews.
Once all of your PRs are merged, you'll chat as a group to:

- assess where your project is
- make sure that your codeberg issues accurately capture the most 
important work for you to focus on next
- assign at least one issue to each team member

Then you'll get to work! Pairing is definitely encouraged - if two team members
want to pair, decide which of your issues you'll work on first.

### Homework 

Same as last time - make sure everyone has an issue they can work on for homework.
Issues should be defined in a way that they are a reasonable amount of work to 
finish before class on Tuesday. Everyone should strive to have a PR ready for 
review by Tuesday, or at least should have some commits that show a valiant 
effort =)
