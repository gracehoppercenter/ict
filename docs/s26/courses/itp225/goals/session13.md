## What We'll Do In Class

### Stand Up

Let's start class with a [standup meeting](https://www.agile-academy.com/en/scrum-master/daily-standup/). We'll work to build this muscle over the next 
couple classes. 

### Grading Update

I'll give a quick update about the scraper that I'm working on for grading.

### Planning

Let's check in and come up with a plan for the next few classes. Here are the
decisions we need to make:

- How much longer will we work on our current projects?
- How will we assign groups and projects for our next round?

### Team Project Work

Keep on keepin' on! As before, work in this order:

1. As a whole team, work together to discuss and merge all open PRs.
2. As a whole team, make sure your issues reflect the work that you need to do
and there are enough of them so that everyone has something to work on
3. Assign issues, and get to work!

### Homework 

Same as last time - make sure everyone has an issue they can work on for homework.
Issues should be defined in a way that they are a reasonable amount of work to 
finish before class on Tuesday. Everyone should strive to have a PR ready for 
review by Tuesday, or at least should have some commits that show a valiant 
effort =)
