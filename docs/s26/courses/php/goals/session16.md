# What do we mean by HTML Entities and Image Maps?

### HTML Entities
* HTML entities (character entity references) are special codes that represent specific characters or symbols in HTML.

* They are used to display characters that have special meanings or cannot be directly typed or displayed in HTML. 
* They are denoted by an ampersand (&) followed by a specific code or name, and then closed with a semicolon (;).

### Image Maps
* mage maps allow you to create interactive and clickable areas within an image to generate super features such as<br> interactive diagrams, clickable infographics, or dynamic navigation menus.

* How do you do it? You need to divide an image into clickable areas, called hotspots,<br> where each hotspot can be linked to a specific destination, such as a web page or an action.
