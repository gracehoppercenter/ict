### Below, we will be discussing the Various Color Models in CSS
### The HEX Model

* As you also might remember from the HTML Essentials course, the HEX model is a web-friendly extension of RGB.<br>It employs hexadecimal notation to express colors and communicate RGB values using a combination of numbers and letters.

* In the hex model, colors are defined using a six-character code, starting with a hash symbol<br> (#) followed by two characters representing the intensity of red, two for green, and two for blue. <br>Each pair of characters represents a value in hexadecimal notation, which ranges from 00 (no intensity) to FF (maximum intensity).

* For example, pure red in RGB (rgb(255, 0, 0)) is represented as #FF0000 in the hex model. Similarly,<br> pure green in RGB (rgb(0, 255, 0)) is #00FF00, and pure blue in RGB (rgb(0, 0, 255)) is #0000FF.

### The HSL Model

* The HSL (Hue-Saturation-Lightness) model defines colors based on three main components: hue, saturation, and lightness.<br> Unlike the RGB model, which is based on additive color mixing, the HSL model approaches color in a more human-centric manner, making it easier to understand and manipulate:

* Hue – represents the actual color itself, ranging from 0 to 360 degrees on the color wheel. <br>It's like choosing a specific color from a circular spectrum. Red is typically at 0 degrees, green at 120 degrees, and blue at 240 degrees.
