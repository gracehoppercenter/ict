### Top Chef

Before we actually start designing websites for clients, let's pretend.

With the folks at your table, you'll design and create a menu website for an imaginary client. I have a bunch of clients written down, and you'll randomly pick one.

First - work with your table to hand-draw a web page. Decide how your page should be divided into categories, how those categories should be laid out on the page, and then come up with a some content to fill the page.

Once your group has agreed on a page design, everyone should implement the page themselves in a file called `practice/top_chef.html`. I'll expect that your design and code shows that you're being thoughtful about: design elements, semantic HTML, CSS selectors and styles, Grid, Color Palettes, and fonts.

At the end of the time, select one group member to share.
