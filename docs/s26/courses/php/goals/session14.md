# What do we mean by HTML Best Practices?

###  HTML Best Practices

Writing HTML code that follows best practices is essential for creating well-structured, accessible, and maintainable web pages. Adhering to these guidelines ensures that your code is readable, performs optimally, and is compatible across different devices and browsers.

### Example:
* Use semantic HTML--like: &lt;header&gt;,&lt;nav&gt;,&lt;main&gt;.
* Maintain consistent indentation and formatting.
* Avoid deprecated tags like &lt;center&gt;, &lt;font&gt;, and &lt;strike&gt;. Instead, use CSS for styling and layout, and use appropriate HTML tags. Similarly, 
* Avoid deprecated attributes such as frame.
