## What is an Attributes?

* Computing (HTML/XML): Attributes extend elements, often in name="value" format,<br> such as &lt;img src="image.jpg" alt="Description"&gt;, where src and alt are attributes.
### Global Attributes

* class: Defines a class name for CSS styling (&lt;div class="container"&gt;).
* id: Specifies a unique identifier for an element (&lt;span id="unique"&gt;).
* style: Adds inline CSS rules (&lt;p&gt; style="color:red;"&lt;/p&gt;).
