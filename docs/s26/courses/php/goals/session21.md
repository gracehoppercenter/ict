### What is a CSS Rules?
* A CSS rule, also known as a style rule, is a set of instructions that defines how a specific <br>HTML element or group of elements should be styled and presented on a web page. It is composed of a selector and its <br>associated declaration block (a set of properties and their corresponding values enclosed in curly braces).
