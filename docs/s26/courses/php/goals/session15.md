# What do we mean by Favicons and iFrames in Web development?

### Favicons
* A favicon is a small icon that is associated with a website. <br>It appears in the browser's tab or bookmark bar, providing a visual representation of the website.

### Example:
![An example of favicon on a website in the below image](../base/images/favicon.png)

### iFrames
* iFrames (short for inline frames) are HTML elements that act as a window into another web page or document.

To create an iFrame, simply use the &lt;iframe&gt; tag in your HTML code. <br>It allows you to specify the source of the content you want to embed and use attributes to customize its appearance and behavior.
