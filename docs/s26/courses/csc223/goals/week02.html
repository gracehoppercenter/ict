Thursday and Friday, February 12th and 13th

Classwork / Homework / Evaluation

During our early-release Wednesday some of our better students in our 3B section (the ones who weren't playing games instead, making their teacher feel that he was a failure as an educator) looked into the best resources we could use for our study of data structures and algorithms using C.

The resource of choice is one I've used before, which both I and the students who used it liked very much, Data Structures Using C by Reema Thareja. The book uses a Windows version of ANSI C, so we'll need to make changes to get sample code to compile on our K&R C compiler, but that's part of the fun. The algorithms are well explained and nice illustrated.
